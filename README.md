# A1 우편 — 발송·반송 (조립식 모듈)

에이원코리아 업무 웹(`total`)의 **우편 발송·반송**을 따로 떼어 낸 모듈입니다.
서버 없이 바로 돌아가고, 주소 한 줄만 바꾸면 `total`과 붙습니다.

## 무엇을 하나

**보낼 것**
- 고객 자료실에 증권·가입증명서가 올라오면 자동으로 쌓입니다. (납입증명서 제외)
- ‘우편 안 받음’ 고객은 빠지고, 지입사 계약은 `지입사 ○○` 로 표시됩니다.
- 고르고 **선택 발송** → 발송일자(`POST_SNDNG_DT`)와 그 순간의 주소가 기록됩니다.
- **폼텍 라벨**(3열×7행, 시작 칸 지정) · **발송 대장**(A4 인쇄) · **CSV**로 바로 뽑습니다.

**반송**
- 돌아온 봉투를 이름·봉투 주소·차량/건설기계 번호·증권번호·전화 끝 4자리로 찾아 등록합니다.
- 기다리는 시간(기본 10분) 뒤 고객에게 **주소 확인 링크 문자**가 나갑니다. 그 사이 취소 가능.
- 지입사 계약은 고객 대신 **지입사 담당자에게 링크 없이** 문자를 보냅니다.
- 같은 고객 봉투가 여러 장이면 한 건으로 묶고 문자는 1통, 다시 보낸 뒤 또 오면 2차로 셉니다.
- 3일 무응답이면 한 번 더, 7일이면 ‘연락 필요’로 내 할 일에 섭니다.

**고객 주소 확인 페이지** (`address-confirm.html`)
- 생년월일 6자리(법인은 사업자번호 10자리)로 확인 → 보낸 주소·사유 확인
- 주소 찾기 + 상세주소 필수(없으면 ‘상세주소 없음’을 눌러야 저장) 또는 ‘위 주소가 맞아요’
- 저장하면 고객 주소가 바로 바뀌고 이전 주소가 남습니다.
- **재발송 대기열**과 **업무팀 할 일(보험사 주소 반영)** 이 자동으로 생깁니다.

**현황·분기**
- 보낸 우편 · 반송 · 반송률 · 주소 고침 · **전자로 열어 봄** · 우편료
- 분기 회의에서 ‘계속 보냄 / 그만 — 전자만’을 기록, 지난 분기는 잠김
- 고객별 **회사 기준 / 항상 우편 / 우편 안 받음**

## 바로 보기 (데모)

정적 서버만 있으면 됩니다.

```bash
cd work/a1-post-module
python3 -m http.server 8791 --bind 127.0.0.1
# http://127.0.0.1:8791/
```

데모 자료는 모두 가짜입니다. ‘＋ 새 증권 등록’으로 자료실 등록 → 자동 목록을 시험할 수 있고,
반송 상세에서 고객 주소 링크를 열어 고객 화면까지 이어서 볼 수 있습니다.

## total에 붙이기

`assets/config.js`

```js
window.A1POST_CONFIG = {
  mode: 'rest',            // demo | rest
  apiBase: '',             // 같은 서버면 ''
  customerPage: '/addr'    // 서버가 만드는 고객 페이지
};
```

엔드포인트·데이터 표·권한·문자 문구·개인정보 기준은 **[INTEGRATION.md](INTEGRATION.md)** 에 전부 적어 두었습니다.
